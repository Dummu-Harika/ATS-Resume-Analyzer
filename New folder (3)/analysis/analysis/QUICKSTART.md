# Quick Start Guide

## ✅ Easy Way - Use the Startup Script

Simply double-click: **`start.bat`**

This will automatically:
1. Start the backend server (port 8000)
2. Start the frontend server (port 5173)
3. Open two terminal windows

Then open your browser to: **http://localhost:5173**

---

## 📝 Manual Way

### Step 1: Start Backend

Open a terminal and run:
```bash
cd d:\analysis\backend
python main.py
```

### Step 2: Start Frontend

Open another terminal and run:
```bash
cd d:\analysis\frontend
npm run dev
```

### Step 3: Open Application

Open your browser to: **http://localhost:5173**

---

## 🎯 How to Use

1. **Fill the form** with your details
2. **Select a domain** (e.g., Full Stack Development)
3. **Add skills** (e.g., "Python, React, AWS")
4. Click **"Start Interview"**
5. **Record answers** using the microphone
6. **View evaluations** after each answer
7. **See final results** with recommendation

---

## 🛑 To Stop

Press `Ctrl+C` in both terminal windows

---

## ⚠️ Important

- Use **Chrome** or **Edge** browser
- Allow **microphone access**
